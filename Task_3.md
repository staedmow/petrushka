## Part 1. Построить верхнеуровневую архитектурую схему - как должна работать отправка PUSH уведомлений в данном приложении. Можно просто в виде блок схем. Считаем, что на бэкенде микросервисная архитектура.

## Схема работы

```
[Мобильное приложение]  <-- Push-уведомление -->  [Firebase Cloud Messaging (FCM) / Apple Push Notification Service (APNs)]
         ^                                                                          |
         |                                                                          |
         | Регистрация токена                                                  Отправка push-уведомления
         |                                                                          |
         v                                                                          |
[Сервис подписок на push]                                                 [Сервис отправки уведомлений]
         ^                                                                          ^
         |                                                                          |
         | Получение токена устройства                                        Получение задачи на отправку
         |                                                                          |
         |                                                                          |
[Мобильное приложение]                                                   [Брокер сообщений (Kafka/RabbitMQ)]
                                                                                    ^
                                                                                    |
                                                                                    | Публикация событий
                                                                                    |
                                                                         [Микросервисы-источники]
                                                                         - Сервис заказов (статус заказа)
                                                                         - Сервис корзины (забытая корзина)
                                                                         - Маркетинговый сервис (рекламные рассылки)

# Краткое описание работы:
1. Мобильное приложение при запуске регистрирует токен устройства в Сервисе подписок на push.
2. Микросервисы-источники публикуют события (заказ отменён, корзина забыта, рекламная акция) в Брокер сообщений (например, Kafka).
3. Сервис отправки уведомлений слушает брокер, берёт событие, находит нужные токены в Сервисе подписок и формирует запрос к FCM/APNs.
4. FCM/APNs доставляют push-уведомление на устройство пользователя.
